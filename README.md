# dc-dc
Импульсный понижающий dc-dc преобразователь 24v-5v
Понижающий преобразователь для работы от промышленной сети 24v. Защита по току обеспечена самовосстанавливающимся предохранителем. Выдает 5v на выходе. Может использоваться для датчиков или логики. Нагрузка до 2A
Построен на базе LMR14030SDDAR.
Содержит защиту от переполюсовки на mosfet и п-образный фильтр
Плата 4-слойная по классической схеме сигнальный-земля-питание-сигнальный. Земля питающей сети и преобразователя разделены.
